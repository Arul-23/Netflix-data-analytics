# Netflix Data Analytics Project

## Overview
This project analyzes Netflix content data using Python and Pandas.

## Tasks Performed
- Data Cleaning and Preprocessing
- Content Type Analysis
- Country-Wise Content Analysis
- Release Year Trend Analysis
- Content Rating and Genre Analysis
- Netflix Business Insights

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights
- Movies are the largest content type.
- Netflix has a global content presence.
- Content production increased significantly over the years.
- Rating and genre analysis helps understand audience segments.

## Project Status
Completed as part of an internship project
